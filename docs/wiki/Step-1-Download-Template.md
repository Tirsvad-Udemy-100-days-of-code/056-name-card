# Step 1: Download the template

Download the "Identity" template from [html5up.net](https://html5up.net) (the lecture offers it as a zip) and unzip it. It is a plain static site: `index.html`, a CSS folder, web fonts and images. Open `index.html` in a browser and it works without any server.

![Step 1: the template as downloaded](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/056-name-card/raw/branch/main/docs/screenshots/step-1-template-download.png)

## What we gained

- A static site is a folder of files that links to each other with relative paths.
- The template is free under CC BY 3.0, so the credit to HTML5 UP must stay on the page.
- You know which files you must later sort into `templates/` and `static/`.
