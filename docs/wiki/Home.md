# name-card wiki

The final project of Day 56 of Udemy's *100 Days of Code*: a personal name card website served by Flask from the HTML5 UP "Identity" template. Each page below follows one lecture step and says what we gained from it.

| Page | What you gain |
| --- | --- |
| [Step 1: Download the template](Step-1-Download-Template) | Download the template and look at a static site |
| [Step 2: Create the Flask server](Step-2-Flask-Server) | Serve it with Flask and see why the page looks broken |
| [Step 3: Point the page at the static folder](Step-3-Static-Files) | Make the template render with the `static/` folder |
| [Step 4: Make it your own](Step-4-Personalise) | Make the card your own and keep the attribution |
| [Run and test](Run-and-Test) | Create a `.venv`, run the app, the tests and the screenshots |
